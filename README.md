# Aplica Technologies — Concept 02
Meeting-aligned static design preview. Blue-led, English-only, simpler navigation, no invented numerical results, endorsements or delivery-time promises.

Run: `python3 -m http.server 4173 --bind 0.0.0.0`

Files: index.html, styles.css, script.js and self-hosted fonts under assets/fonts.

## Client approvals required
- Proposed positioning, geographic wording and all service/product coverage.
- Proposed delivery process and company description.
- Typographic wordmark and blue palette: not a completed rebrand.
- Actual team photography, customer interviews, case evidence and permissions.
- Sales email before launch.

Contact form validates and opens a mailto draft; it never claims to submit. No analytics, tracking or CRM integration. No Arabic or domain migration in this scope.

Production work remains separate: WordPress build, approved real URL architecture, SEO migration/redirect mapping, legal pages, accessibility and browser testing, analytics and secured enquiry backend.

Preview requests search engines not to index via meta robots. This is not access control.
